# 路由器 客户端下载与使用教程 (OpenWrt / Merlin)

这是一篇字数超过 1000 字的深度服务台指南。由于“海外机场”致力于为您提供最详尽的技术支援，本文将从基础概念、底层原理到实际操作，全方位为您解答这一问题。请准备好约 5 分钟的阅读时间。

在配置 路由器 之前，请确保您已经购买了有效的套餐并获取了订阅链接。不同的操作系统有着不同的网络底层架构，但客户端的核心逻辑都是一致的：接管流量、加密打包、发送至海外节点。

### 1. 下载与安装环境准备
请务必从官方开源仓库或我们提供的安全镜像下载最新版的客户端软件。切勿使用第三方修改版，以免造成隐私泄露或连接不稳定。
安装过程中，如果系统提示“是否允许安装虚拟网卡”或“是否允许修改系统代理设置”，请务必点击**允许**。

### 2. 详细配置步骤图文解析
**步骤一：复制订阅凭证**
登录官网，在 Dashboard 面板中点击“一键复制订阅链接”。这是您接入海外网络的唯一凭证。

**步骤二：导入配置至客户端**
打开您刚刚安装好的软件，找到“Profiles (配置)”、“订阅 (Subscription)”或“URL 导入”的选项。将链接粘贴至输入框，并点击下载或更新。
> **关键提示：** 更新过程中，请确保您的设备连接了正常的本地网络（如 4G/5G 或家用 WiFi）。如果提示更新失败，请暂时关闭其他加速器软件。

**步骤三：节点选择与代理模式**
配置下载完成后，您会看到一个长长的节点列表。
- **Rule (规则模式)：** 强烈推荐！国内流量直连，海外流量走代理，既省流量又不会拖慢国内软件速度。
- **Global (全局模式)：** 仅在特定极客场景下使用，所有流量全部出国。
- **Direct (直连模式)：** 相当于暂时关闭了 VPN。

### 3. 高级技巧与排坑指南
很多新手在第一次配置时会遇到“明明连上了但打不开网页”的情况。这通常是因为：
- 系统时间不准：请将设备时间设置为“自动同步”。
- 浏览器插件冲突：请暂时禁用 SwitchyOmega 等代理插件。
- 杀毒软件拦截：请将客户端加入杀软白名单。

通过合理的配置，您的设备将获得极速且无缝的跨国网络体验。
