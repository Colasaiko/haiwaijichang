# 第一次使用怎么开始？新手完整接入指南

欢迎来到海外机场服务台！如果您是第一次接触跨境网络服务，面对“节点”、“订阅”、“客户端”等专业词汇，可能会感到无从下手。请不要担心，本指南专为零基础用户编写，我们将用最通俗易懂的语言，带您一步步完成从购买到成功连接的全过程。

本文包含约 1500 字的详尽说明，建议您耐心阅读。只要按照顺序操作，只需 5 分钟，您就能顺利开启通往全球网络的航班。

## 第一部分：理解基础概念（我们在做什么？）

在开始动手之前，我们需要先明白几个核心概念。很多新手连不上网络，往往是因为混淆了这三者的关系。

### 1. 服务商（机场）与订阅链接
“海外机场”就像是一家航空公司。您在我们这里购买的套餐（例如“亚洲不限速套餐”），就是一张长期的机票。
购买成功后，系统会为您生成一串极长的网址，这被称为**“订阅链接 (Subscription URL)”**。
这串链接是您账号的核心凭证，里面包含了数百台服务器的 IP 地址、端口和加密密码。**请绝对不要将这串链接发给任何人**，否则他人可以盗用您的流量。

### 2. 客户端（软件工具）
有了机票（订阅链接），您还需要一架飞机来载您起飞，这就是**“客户端”**。
客户端是安装在您设备上的一个软件（比如 Windows 上的 Clash Verge，手机上的 Shadowrocket / V2rayNG）。客户端本身是免费且开源的，它就像一个没有任何联系人的空手机，只有当您把“订阅链接”导入进去之后，它才知道该连接到哪台服务器。

### 3. 节点（服务器路线）
当您在客户端中成功导入订阅后，您会看到几十甚至上百个带有国家国旗的名字（如“🇺🇸 美国 优化直连 01”）。这些就是**“节点”**。
节点就是您这架航班的目的地。选择日本节点，您的网络身份就会变成日本；选择美国节点，您就可以访问仅限美国地区开放的服务（如 ChatGPT）。

## 第二部分：标准起飞流程 (Step-by-Step)

无论您使用的是电脑、手机还是平板，基础的配置逻辑永远只有简单的“三步走”。

### 第一步：下载并安装合适的客户端
请根据您的设备类型，下载官方推荐的客户端。请务必认准官方或开源原版，切勿在来历不明的网站下载被植入木马的修改版。

*   **Windows 用户：** 我们强烈推荐使用 **Clash Verge Rev** 或 **v2rayN**。它们支持最新的协议，且具备自动分流功能（国内网站不走代理，速度飞快）。
*   **macOS 用户：** 推荐使用 **ClashX Pro** 或 **Surge**（需单独购买）。
*   **Android (安卓) 用户：** 推荐使用 **Clash for Android** 或 **v2rayNG**。
*   **iOS (苹果) 用户：** 由于系统封闭性，您需要使用非国区 Apple ID 登录 App Store，下载 **Shadowrocket** (小火箭) 或 **Quantumult X** (圈X)。

> 💡 **机长提示：** 如果您不知道去哪里下载这些软件，请返回我们的帮助中心首页，在“客户端下载与设置”板块中，有每个软件的专属下载通道和图文教程。

### 第二步：获取并导入“订阅链接”
这是最核心的一步。很多用户卡在这里是因为复制错误。

1.  登录海外机场官网，进入您的 **用户后台 / 控制面板**。
2.  在首页最显眼的位置，您会看到一个名为 **“一键导入”** 或 **“复制订阅链接”** 的按钮。
3.  点击“复制订阅链接”（请确保复制了完整的 URL，通常以 `https://` 开头，末尾是一长串无规律字母）。
4.  打开您刚刚下载好的客户端软件。
5.  在软件中找到名为 **“Profiles (配置)”**、**“订阅设置”** 或 **“服务器订阅”** 的菜单。
6.  将复制的链接粘贴进去，然后点击 **“Download (下载)”** 或 **“更新订阅”**。
7.  如果操作正确，您会看到软件瞬间加载出了大量的节点列表。

### 第三步：选择节点并启动代理
现在，您的软件已经具备了连接世界的能力。

1.  回到软件的 **“Proxies (代理/节点选择)”** 页面。
2.  在这里，您会看到所有的国家列表。我们建议新手直接选择标有 **“自动选择”** 或 **“延迟最低”** 的选项。如果您有明确目的（比如要用 ChatGPT），请手动点击一个 **美国 (US)** 或 **日本 (JP)** 的节点。
3.  最后一步，找到软件的 **“System Proxy (系统代理)”** 开关，将其打开。（在部分手机软件上，是一个大大的“启动”或小飞机图标）。
4.  此时，您的设备可能需要您授权创建 VPN 连接，请点击“允许”或输入开机密码。

恭喜！当开关变亮，或者手机顶部状态栏出现 `VPN` 小图标时，您的设备就已经成功起飞了。

## 第三部分：测试连接与高级建议

连接成功后，怎么验证自己真的“出国”了呢？

### 如何测试？
请打开您的浏览器，在地址栏输入 `youtube.com` 或 `google.com`。如果网页能够迅速打开，并且视频能够流畅播放，说明您的配置完全正确。
您也可以在 Google 搜索栏中输入 `my ip`，搜索结果会显示您当前的 IP 地址。如果显示的位置是您刚才选择的节点国家（比如东京），那就大功告成了。

### 新手必看的避坑指南
为了确保您接下来的航程安全且愉快，请务必记住以下几条原则：

1.  **不要一直开着全局模式 (Global Mode)：** 大多数客户端（如 Clash）默认是“规则模式 (Rule)”。这意味着您访问国内淘宝、微信时，流量依然走国内宽带，不会消耗套餐流量；只有访问海外网站时才会走节点。如果您手贱开启了“全局模式”，那么不仅国内网站会变得极度卡顿，您的套餐流量也会被疯狂消耗。
2.  **订阅链接会过期：** 当您修改了官网登录密码，或者套餐到期续费后，原来的订阅链接可能会失效。这时候只需要回到官网重新复制一次，在软件里更新即可。
3.  **延迟高不等于速度慢：** 很多新手喜欢盯着软件里的 `Timeout` 测速结果看。请记住，物理距离决定了连接美国节点的基础延迟至少有 150ms。只要带宽足够，看 4K 视频依然会非常丝滑。不要为了追求绝对的“绿色低延迟”而一直频繁切换节点。

## 结语
以上就是第一次使用海外机场的完整流程。掌握了“复制链接 -> 导入软件 -> 启动系统代理”这套逻辑，以后无论更换什么设备，您都能游刃有余。

如果在操作过程中遇到了“节点全部显示超时”或者“开关打开了依然上不了网”的问题，请继续阅读本站提供的故障排查指南。祝您旅途愉快！
